# Sobre o Projeto - Jogo da Forca

Desenvolver games é uma excelente maneira de exercitar conceitos fundamentais de lógica de programação como algoritmos, variáveis, tipos de dados, estruturas condicionais e de repetição e operadores lógicos e aritiméticos. Além de explorar e aprender os recursos disponíveis na linguagem utilizada para manipulação de dados. Coisas frequentimente utilizadas no dia a dia por quem trabalha com desenvolvimento, e por vezes requeridas em testes e desafios técnicos.

Este projeto foi iniciado com o intuito de exercitar e explorar estes recursos do Javascript, e exercitar também o desenvolvimento voltado ao front-end com utilização de HTML e CSS para criação de interface responsiva.
